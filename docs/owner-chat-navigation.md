# 점주 채팅 진입 보완

2026-11-08.

- 기존 점주 화면은 마이페이지 하단에만 채팅 진입이 있었다. 점주도 하단 `홈 / 공고관리 / 근무관리 / 채팅 / 마이페이지`에서 바로 진입하도록 변경했다.
- 기존 공통 채팅 목록/상세와 점주 채팅방 경로를 재사용한다. 기존 마이페이지 진입도 유지한다.
- 화면 명세의 점주 하단 메뉴를 변경에 맞춰 갱신했다. API와 메시지 전송/읽음 계약은 변경하지 않았다.
- 서버의 점주/알바생 테스트 계정에 같은 채팅방 2개가 존재함을 조회했고, 다른 알바생 테스트 계정의 목록은 비어 있었다. 자격증명/메시지 본문은 기록하지 않는다. 조회용 세션은 모두 로그아웃했다. 실제 메시지는 보내지 않았다.
- `./docs/scripts/verify.sh` 통과. 100 tests, 실패/오류 0.
- 로컬 `build/presentation/` APK를 새 빌드로 갱신했다. APK/로컬 키는 Git에 넣지 않는다.
- 작업 시작 전 존재하던 인증/지도/공통 UI 및 에이전트 문서 수정은 보존한다. 이 작업의 코드 변경은 OwnerRootScreen 하나이며 기존 변경을 함께 커밋하지 않는다.

- 에뮬레이터 live 점주 로그인 후 하단 5개 탭 및 실제 대화 목록을 확인했다. 실제 채팅방 진입 후 메시지 입력칸과 뒤로 버튼까지 확인했다. 전송은 실행하지 않았다.
