# 화면 정의서 (UI Specification)
**긴급 아르바이트 매칭 서비스**

---

## 1. 공통 화면

### 1-1. 온보딩 / 스플래시

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 스플래시 | 앱 로고 | 서비스 로고 및 슬로건 표시 | 2초 후 자동 이동 |
| | 자동 로그인 처리 | 기존 세션 존재 시 자동 로그인 후 메인 화면으로 이동 | 토큰 기반 |
| 온보딩 | 온보딩 슬라이드 | 서비스 핵심 기능 소개 | 최초 1회 |
| | 시작하기 버튼 | 온보딩 완료 후 회원가입/로그인 화면으로 이동 | 필수 |

---

### 1-2. 회원가입

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 유형 선택 | 점주 선택 | 사용자 유형을 '점주'로 선택 | 필수 |
| | 알바생 선택 | 사용자 유형을 '알바생'으로 선택 | 필수 |
| 기본 정보 | 이름 입력 | 한글/영문 2~20자 | 필수 |
| | 이메일 입력 | 이메일 형식 검증 (example@domain.com) | 필수 |
| | 비밀번호 입력 | 영문, 숫자, 특수문자 포함 8~20자 | 필수 |
| | 비밀번호 확인 | 비밀번호 일치 여부 실시간 검증 | 필수 |
| 인증 | 이메일 인증 | 인증 코드 6자리 입력 (유효시간 5분) | 필수 |
| | 휴대폰 인증 | SMS 인증 코드 6자리 입력 (유효시간 3분) | 선택 |
| 사업자 정보 | 사업자등록번호 | 10자리 숫자, 국세청 API 실시간 검증 | 점주 필수 |
| | 업종 선택 | 카테고리 선택 (음식점, 카페, 편의점 등) | 점주 필수 |
| | 가게 위치 | 지도 기반 위치 설정 또는 주소 직접 입력 | 점주 필수 |
| 가입 완료 | 완료 메시지 | 가입 완료 안내 및 메인 화면으로 이동 버튼 | |

---

### 1-3. 로그인

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 로그인 | 이메일 입력 | 이메일 형식, 영문·숫자 혼합 6~30자 | 필수 |
| | 비밀번호 입력 | 영문, 숫자, 특수문자 포함 | 필수 |
| | 로그인 버튼 | 자격증명 검증 후 유형별 메인 화면 이동 | |
| | 소셜 로그인 | 카카오 / 네이버 로그인 지원 | 선택 |
| | 비밀번호 찾기 | 이메일로 임시 비밀번호 발송 | |

## 2. 점주 화면

### 2-1. 점주 홈

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 점주 홈 | 공고 목록 | 등록된 공고 카드 리스트 (상태: 모집중·마감·완료) | |
| | 공고 상태 뱃지 | 모집중(초록) / 마감(회색) 색상 구분 | |
| | 지원자 수 표시 | 각 공고별 현재 지원자 수 실시간 표시 | |
| | 긴급 공고 등록 버튼 | 우측 하단 버튼, 탭 시 공고 등록 화면으로 이동 | 필수 |
| | 하단 내비게이션 | 홈 / 공고관리 / 근무관리 / 마이페이지 | |

---

### 2-2. 공고 등록

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 공고 등록 | 근무 날짜 | 달력 팝업에서 날짜 선택, 당일 또는 익일 제한 | 필수 |
| | 근무 시간 | 시작 시간 / 종료 시간 선택 (30분 단위) | 필수 |
| | 업무 내용 | 최대 200자 텍스트 입력 | 필수 |
| | 기본 시급 | 숫자 입력, 최저시급(10,320원) 이상 검증 | 필수 |
| | 자동 시급 가산 | 긴급도·시간대 기반 가산액 자동 계산 후 표시 | 시스템 자동 |
| | 모집 인원 | 1~10명 숫자 입력 또는 스테퍼 | 필수 |
| | 모집 반경 | 500m / 1km / 3km / 5km 선택 | 필수 |
| | 위치 정보 | 현재 위치 자동 입력 또는 지도 선택, 주소 표시 | 필수 |
| | 업종 카테고리 | 음식점/카페/편의점 등 카테고리 선택 | 필수 |
| | 등록 버튼 | 등록 버튼 후 확인/실패 안내 팝업 | |
| 등록 완료 | 등록 확인 팝업 | 등록 성공 메시지, 공고 상세 또는 홈 이동 버튼 | |
| 등록 실패 | 실패 안내 팝업 | 오류 사유 안내 및 재입력 유도 | |

---

### 2-3. 지원자 관리

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 지원자 목록 | 지원자 카드 | 프로필 이미지, 이름, 평점, 예상 도착 시간, 매칭 점수 표시 | |
| | 노쇼 예측 뱃지 | 노쇼 위험도 낮음/주의/높음 색상 표시 (녹/황/적) | AI 예측 |
| | 업종 경험 표시 | 해당 업종 근무 이력 여부 아이콘 표시 | |
| 지원자 상세 | 프로필 정보 | 이름, 사진, 나이, 신뢰도 점수 | |
| | 근무 이력 | 최근 5건 근무 이력 (장소, 날짜, 평점) | |
| | 노쇼 이력 | 누적 노쇼 횟수 및 최근 노쇼 일자 | |
| | 예상 도착 시간 | 현재 위치 기반 도착 예정 시간 (분 단위) | GPS |
| | 매칭 확정 버튼 | 해당 지원자 매칭 확정, 채팅방 생성 및 알림 발송 | |

---

### 2-4. 근무 관리

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 근무 현황 | 출근 확인 | GPS 기반 출근 인증 여부 표시 (인증완료/미완료) | |
| | 실시간 위치 | 알바생의 현재 위치를 지도에 표시 | GPS |
| | 근무 진행 타이머 | 근무 시작 시각 ~ 현재 경과 시간 표시 | |
| | 노쇼 확정 버튼 | 근무 시작 후 30분 초과 시 활성화, 노쇼 처리 | 시간 조건 |
| | 근무 완료 버튼 | 근무 종료 처리, 정산 트리거 | |
| 정산 | 정산 내역 | 총 근무시간, 시급, 가산액, 최종 지급액 표시 | |
| | 정산 확인 버튼 | 정산 금액 확인 후 지급 승인 | |

### 2-5. 노쇼 처리

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 노쇼 확정 | 노쇼 확정 팝업 | 노쇼 확정 전 재확인 다이얼로그, 확인/취소 버튼 | |
| | 자동 재매칭 안내 | 노쇼 확정 후 자동 재매칭 진행 안내 메시지 | |

| | 재매칭 실패 | 공고 재오픈 또는 마감 선택 안내 | |

### 2-6. 지난 공고 관리

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 지난 공고 목록 | 공고 카드 | 날짜, 업무, 매칭된 알바생 이름, 상태(완료/노쇼/분쟁) 표시 | |

| | 정산 내역 확인 | 최종 정산 금액 및 지급 일시 표시 | |

## 3. 알바생 화면

### 3-1. 홈 화면 조회

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 홈 | 근무 가능 토글 스위치 | on: 즉시 지원 가능한 공고 표시 / off: 전체 공고 표시 | 기본값 off |
| | 즉시 지원 버튼 | 모집 중 상태일 때 활성화, 탭 시 즉시 지원 처리 | 성공 시 지원 완료 상태 표시 |
| | 하단 내비게이션 | 홈 / 탐색 / 근무관리 / 채팅 / 마이페이지 | |
| | 긴급 공고 | 마감까지 일정 시간 이하로 남은 긴급 공고 표시 | |
| | 추천 공고 | 온보딩 시 입력한 사용자의 희망 정보에 충족하는 추천 공고 표시 | |

---

### 3-2. 공고 탐색

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 공고 탐색 | 리스트 보기 | 총 공고 개수 표시, 공고 카드 리스트 형태 표시 | 기본 |
| | 리스트 보기 - 긴급 공고 카드 | 근무지 이름, 업종, 근무 시간, 시급(기본 시급+가산 시급), 지원 종료까지 남은 시간, 근무지와의 거리, 즉시 지원 버튼 표시 | |
| | 리스트 보기 - 추천 공고 카드 | 근무지 이름, 업종, 근무 시간, 근무지와의 거리, 즉시 지원 버튼 표시 | |
| | 지도 보기 | 지도 위 공고 핀 표시, 탭 시 공고 미리보기 카드 팝업 | |
| | 필터 | 설정 버튼 클릭 시 팝업창 노출, 거리 (500m~10km) / 시급 범위 / 시간대 / 업종 멀티 필터 | |
| | 긴급 공고 뱃지 | 긴급도 '높음' 이상 공고에 긴급 뱃지 강조 표시 | |
| | 거리 표시 | 현재 위치 기준 각 공고까지 거리 표시 (m/km) | GPS |
| | 즉시 지원 버튼 | 모집 중 상태일 때 활성화, 탭 시 즉시 지원 처리 | 성공 시 지원 완료 상태 표시 |

## 4. 마이페이지

### 4-1. 프로필 설정

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 프로필 | 프로필 이미지 | 갤러리 또는 카메라 선택, JPG/PNG 5MB 이하 | |
| | 이름 수정 | 한글/영문 2~20자 | 필수 |
| | 연락처 수정 | 휴대폰 번호, 변경 시 재인증 필요 | |
| | 알림 설정 | Push 알림 / 이메일 알림 / SMS 알림 ON/OFF 토글 | |
| | 로그아웃 | 세션 종료 후 로그인 화면으로 이동 | |
| | 회원 탈퇴 | 탈퇴 확인 팝업 → 비밀번호 재확인 → 탈퇴 처리 | 주의 |
| | 신뢰 점수 | 신뢰 점수 영역 클릭 시 신뢰도 화면으로 이동 | |

---

### 4-2. 신뢰도

| 화면명 | 항목명 | 설명 | 비고 |
|--------|--------|------|------|
| 신뢰도 | 신뢰 점수 | 0~100점 게이지 바 및 등급 표시 | |
| | 노쇼 위험도 | LOW/MIDDLE/HIGH로 노쇼 위험도 표시 | |
