# 채팅 목록 및 연결 공고

2026-11-08. 카카오톡 참고 이미지의 프로필·대화명·최근 메시지·오른쪽 보조 정보 구조를 기존 light-only 테마로 적용했다. 시간 대신 실제 연결 공고의 가게명과 미읽음 배지를 표시한다.

ChatRoomDetailResponse의 실제 ownerMemberId/workerMemberId에서 본인이 아닌 참가자 ID를 매핑한다. 상대 이름·사진 조회 공개 계약은 없어 기본 아이콘과 회원 번호로 표시한다. 이름을 가게명으로 위장하거나 테스트 계정 이름을 하드코딩하지 않는다.

채팅방 상단의 가게 이름 링크는 실제 jobPostId를 보존하여 연결 공고의 주소·지도·일정·급여·내용 상세로 이동한다. 점주에게 알바생 지원 버튼이 노출되지 않도록 공통 읽기 전용 상세를 사용한다. demo 방에도 실제 fixture 공고 ID를 연결했다.

검증: live verify.sh와 demo lint/unit/APK 모두 통과(각 101 tests, 실패·오류 0). 상대 ID 매핑 경계 테스트 추가. 에뮬레이터에서 점주 실제 목록의 오른쪽 가게명/최근 메시지, 방 진입, 가게명 클릭 후 연결된 공고 상세 이동을 확인했다. 메시지를 새로 보내지 않았다. build/presentation의 server.apk/demo.apk 갱신.

기존 다른 작업자의 미커밋 변경은 보존했다. AppNavHost는 이 작업의 채팅 공고 경로/콜백 추가만 선택적으로 커밋한다. 화면 명세 갱신 외 에이전트 정책 문서 변경은 필요 없다.
