# 점주·알바생 UI 구현 현황

기준: 2026-11-01, `feature/#18-ui-completion`, 이슈 #18. 화면 정의는 `docs/UI_Specification.md`, 시각 규칙은 `docs/agent/style_guide.md`를 따릅니다.

이 문서의 **구현**은 Compose 화면 및 앱 내 mock 흐름을 뜻합니다. 서버 연동, 실제 위치 인증, 결제, Push가 완료되었다는 뜻이 아닙니다. API 연결은 별도 브랜치에서 진행합니다.

## 이번 보완

- 신뢰도 화면에 기존 `WorkerWorkRepository`의 근무 일정을 표시합니다. 일정 조회 실패가 신뢰 점수/리뷰 표시를 막지 않도록 별도 loading/error/retry 상태를 둡니다.
- 근무 이력에서 누락된 시급을 표시하고 최근 리뷰는 명세의 3건으로 제한합니다.
- 근무 관리의 데이터 오류를 빈 목록과 구분하여 재시도를 제공합니다.
- 근무 관리에서 지원 현황과 신뢰도/근무 이력을 직접 열 수 있도록 연결합니다.
- 매칭 성공에 축하 애니메이션을 추가하고 메인 이동 버튼이 지원 현황으로 되돌아가던 연결을 수정합니다.
- 알바생 로그아웃 시 기존 역할 선택 화면으로 돌아가 이전 알바생 화면이 뒤로가기로 재등장하지 않도록 합니다.
- 점주와 알바생 마이페이지에 이름 수정 다이얼로그와 한글/영문 2~20자 실시간 검증을 추가합니다. 점주는 기존 profile repository, 알바생은 feature 전용 mock profile repository에 반영합니다. 알바생 알림 설정도 탭 이동 후 유지합니다. 저장은 앱 세션 동안의 mock이며 서버에 반영되지 않습니다.
- 양 역할에서 Android photo picker 및 외부 카메라 촬영로 JPG/PNG 5MB 이하 사진을 선택하고 미리보기를 표시합니다. 저장은 앱 세션 동안만 유지되며 서버 업로드는 없습니다. 카메라 촬영은 후속입니다.
- 일정 mock에 주소와 optional 공고 ID를 추가하고 날짜·가게·시간이 기존 공고와 일치하는 일정만 공고 상세로 연결합니다. 불일치 fixture에는 임의 링크를 만들지 않았습니다.
- 신규 표시 문구는 feature 전용 `strings_worker_ui.xml`을 사용합니다. API 경로·DTO는 변경하지 않습니다. 점주 profile repository에 mock 이름 수정 계약을 추가하고 별도 알바생 profile repository를 둡니다.

## 후속 UI 작업의 선행 조건

1. **GPS 출근:** 현재 `WorkSchedule`에 근무지 좌표/인증 반경/출근 상태가 없습니다. 주소와 검증된 mock 공고 ID는 이번에 추가했습니다. 실제 출근 판정에 필요한 데이터와 반경 정책을 확인한 뒤 위치 권한 요청/거부/위치 비활성/반경 밖 상태를 포함해 구현해야 합니다. 임의 좌표나 인증 성공을 넣지 않았습니다.
2. **공고·계약서·리뷰:** 근무→공고 ID의 실제 서버 매핑, 계약서 파일/내용, 리뷰 작성 기간(명세상 협의), 작성 결과가 필요합니다. mock 중 실제 상세와 일치하는 공고 확인 링크는 연결했습니다. 계약서/리뷰 상세 폼과 저장 API를 임의로 만들지 않았습니다.
3. **계정 설정:** 로그인/회원가입과 연락처 변경/재인증과 실제 프로필 이미지 업로드은 인증 브랜치와 이어 구현합니다. 이름 수정은 이번 요청에서 UI만 mock으로 보완했습니다. 탈퇴 확인 버튼은 현재 실제 탈퇴를 수행하지 않습니다.
4. **지도:** Naver SDK 의존성과 발급된 client ID 설정, 위치 권한/제공 불가 처리, 실제 데이터가 필요합니다.

공통 1-1~1-3 온보딩/회원가입/로그인 화면은 현재 역할 선택 데모로 대체되어 있으며 미구현입니다. 기존 데모 범위 결정에 따라 이번 보완에서 새 인증 흐름을 만들지 않았습니다.

## 검증

- `JAVA_HOME`를 준비된 JDK 17 경로로 설정하고 `./docs/scripts/verify.sh` 실행: lint, 단위 테스트, debug APK 빌드 통과.
- 이름 검증 경계/잘못된 문자, mock 프로필 변경 보존, 잘못된 이름 거부, 연결된 근무-공고의 가게/날짜/시간/주소 일치 회귀 테스트를 추가했습니다.
- Android 에뮬레이터에서 알바생 이름 저장, 근무 관리→신뢰도 이동, 점주 이름 다이얼로그, 양 역할 시스템 사진 선택/미리보기, 알바생 탭 이동 후 사진 보존을 확인했습니다.
- 카메라 촬영·실제 GPS 인증·실제 서버 저장은 이 UI 전용 작업의 검증 대상이 아닙니다.

## 2026-11-02 카메라 UI 체크포인트

- 양 역할에서 외부 카메라 앱으로 촬영하고 JPG/PNG 5MB 제한 검증 후 프로필 미리보기에 사용할 수 있습니다. 앱 전용 cache 경로만 FileProvider로 노출합니다.
- 촬영 취소·카메라 앱 없음·촬영 실패 안내 및 실패한 앱 임시파일 정리를 포함합니다. 갤러리 원본은 삭제하지 않습니다.
- 전체 lint·단위 테스트·debug 빌드는 통과했습니다. 실제 카메라 앱에서 촬영 완료·취소의 에뮬레이터 검증은 사용량 제한으로 아직 수행하지 못했습니다.
- API 모드의 사진 업로드는 서버 계약이 없어 계속 비노출입니다. 이번 변경은 UI 데모의 촬영·미리보기입니다.
