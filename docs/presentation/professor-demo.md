## 이 Mac에서 실행

로컬 산출물은 저장소의 `build/presentation/`에 있다(빌드 파일과 로컬 실행기는 Git에 올리지 않는다).

- `데모 실행.command`: 샘플 데이터가 있는 점주/알바생 시연. 역할 선택에서 시작한다.
- `서버 연동 실행.command`: 실제 서버 로그인/조회. API·서버 데이터/설정이 준비되지 않은 동작은 제한된다.
- 두 실행본은 같은 앱 ID를 사용해 서로 교체 설치된다. 동시에 별도 앱 두 개로 설치된 것이 아니다.
- 에뮬레이터가 꺼져 있으면 실행기가 `test_avd`를 켠다.
- `demo.apk`, `server.apk`는 설치 가능한 개발용 APK다. Play 스토어 배포본은 아니다.

## 권장 시연

1. 데모 실행 → 알바생: 홈 → 탐색 → 공고 상세 → 지원 → 지원 현황/매칭 → 근무 관리 → 마이페이지.
2. 역할 선택으로 돌아가 점주: 공고/지원자 → 근무 관리 → 근무 완료 → 정산/지난 공고. 데모의 노쇼·재매칭은 시뮬레이션이다.
3. 서버 연결을 설명할 때 서버 실행본으로 전환하고 전달받은 테스트 계정으로 로그인한다. 계정/비밀번호는 이 문서에 기록하지 않는다.

라이브의 실제 출근 성공, 결제·공고 공개, 실제 두 계정 채팅/정산 등은 배정 업무 데이터와 외부 설정이 있어야 검증할 수 있다. 화면 구현/계약 테스트와 실제 업무 성공을 구분한다.

## 배포 질문에 대한 답변

“백엔드는 원격 서버에 배포되어 있고, Android 프론트는 APK로 빌드해 로컬 에뮬레이터에서 시연하고 있습니다. APK를 전달해 테스트 설치할 수 있으며, Play 스토어 공개 배포는 아직 하지 않았습니다.”

Android도 배포가 있다. 웹 URL 호스팅 대신 서명된 앱 패키지를 사용자에게 전달/설치하거나 스토어·내부 테스트 채널로 제공한다. 에뮬레이터에서만 실행한 상태를 사용자 대상 정식 배포로 표현하지 않는다.
