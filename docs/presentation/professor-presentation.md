# 교수님 시연 체크포인트

- 사용자 지시에 따라 `design/android-ui-redesign`은 포함하지 않는다.

## 이 Mac에서 실행

로컬 산출물은 저장소의 `build/presentation/`에 있다(빌드 파일과 로컬 실행기는 Git에 올리지 않는다).

- `앱 실행.command`: `app.apk`를 설치하고 실행한다. 에뮬레이터가 꺼져 있으면 `test_avd`를 켠다.
- `app.apk`는 설치 가능한 개발용 APK다. Play 스토어 배포본은 아니다.

## 권장 시연

전달받은 테스트 계정으로 로그인한다. 계정/비밀번호는 이 문서에 기록하지 않는다.

1. 알바생: 홈 → 탐색 → 공고 상세 → 지원 → 지원 현황/매칭 → 근무 관리 → 마이페이지.
2. 점주: 공고/지원자 → 근무 관리 → 근무 완료 → 정산/지난 공고.

실제 출근 성공, 결제·공고 공개, 두 계정 채팅/정산 등은 배정 업무 데이터와 외부 설정이 있어야 검증할 수 있다. 화면 구현/계약 테스트와 실제 업무 성공을 구분한다.

## 배포 질문에 대한 답변

“백엔드는 원격 서버에 배포되어 있고, Android 프론트는 APK로 빌드해 로컬 에뮬레이터에서 시연하고 있습니다. APK를 전달해 테스트 설치할 수 있으며, Play 스토어 공개 배포는 아직 하지 않았습니다.”

Android도 배포가 있다. 웹 URL 호스팅 대신 서명된 앱 패키지를 사용자에게 전달/설치하거나 스토어·내부 테스트 채널로 제공한다. 에뮬레이터에서만 실행한 상태를 사용자 대상 정식 배포로 표현하지 않는다.

공식 문서: https://developer.android.com/studio/publish
